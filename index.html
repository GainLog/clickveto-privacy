ClickVeto Privacy Policy

Effective date: September 19, 2026

ClickVeto is a browser protection extension designed to block unwanted browser actions such as intrusive popups and popunders, suspicious redirect chains, risky downloads, and related advertising or tracking requests. ClickVeto is designed to operate locally in the user's browser.

Data ClickVeto processes

To provide its protection features, ClickVeto may process the following data locally on the user's device:

  • Web history and navigation data: domains, URLs, redirect targets, redirect-chain information, and timestamps that are needed to detect or explain blocked browser actions.
  • User activity: short-lived metadata about trusted clicks, pointer actions, or keyboard activation used to distinguish intentional actions from unwanted popups, redirects, or downloads.
  • Website content: limited page text, links, and element attributes may be inspected locally to detect clearly identified intrusive advertising overlays. ClickVeto does not copy or transmit the full contents of webpages.
  • Download information: download URLs, referrers, filenames, file extensions, MIME types, Chrome danger states, and the user's allow/block decision when required for Download Guard.
  • Extension settings: protection settings, allowlists, blocklists, temporary exceptions, counters, and local protection-log entries.

How the data is used

This information is used only to provide ClickVeto's user-facing protection features, including popup and popunder protection, redirect-chain detection, risky-download protection, website exceptions, and the local protection log.

Local storage and retention

ClickVeto stores settings and protection information in Chrome's local extension storage. The local protection log is limited to up to 200 recent events. Short-lived interaction metadata used to associate a user action with a popup or download is kept only temporarily for protection logic. Users can clear the protection log or reset ClickVeto's settings from the extension interface, and Chrome removes extension data when the extension is removed according to Chrome's behavior.

No sale or advertising use

ClickVeto does not sell user data, does not use browsing data for personalized advertising, and does not transfer browsing activity to advertising platforms, data brokers, or other information resellers.

No ClickVeto analytics or account

ClickVeto does not require a ClickVeto account and does not send the locally processed browsing, activity, website-content, or download data described above to a ClickVeto-operated analytics or telemetry server.

Filter-list updates

When network protection updates its filter data, ClickVeto may download public advertising and tracking filter lists from their published sources. These requests expose the ordinary connection information needed to deliver a file, such as the user's IP address and browser network metadata, to the list host. ClickVeto does not append the user's browsing history or the URLs of pages they visit to those requests.

Optional Pro purchase and license validation

Purchasing ClickVeto Pro is handled by Lemon Squeezy as the merchant of record under its own privacy terms. When a user chooses to activate, validate, restore, or deactivate a Pro license, ClickVeto sends the entered license key and the technical license or installation identifiers required for that request to Lemon Squeezy's License API. ClickVeto does not include the user's browsing history, protection log, or page contents in license requests.

Remote code

ClickVeto does not execute remotely hosted JavaScript or WebAssembly. Executable extension code is included in the extension package distributed through the Chrome Web Store.

Chrome Web Store Limited Use

The use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data accessed by ClickVeto is used only to provide or improve the extension's disclosed single purpose and related user-facing protection features.

Third parties

Except for the user-initiated Pro purchase and license operations and the public filter-list downloads described above, ClickVeto does not share the locally processed user data described in this policy with third parties, except where disclosure may be required by applicable law.

Changes to this policy

If ClickVeto's data practices change, this privacy policy and the Chrome Web Store privacy disclosures will be updated before those changes are released where required.

Contact

For privacy questions, contact the developer using the public contact email listed on ClickVeto's Chrome Web Store listing.
